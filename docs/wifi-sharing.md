# Wi-Fi Sharing

On the tablet, open **Settings → Wi-Fi Sharing → Share files and links…** or
tap **Wi-Fi Sharing** in **Files**. Tap **Start sharing**. Connect the other
device to the same Wi-Fi, open the complete **http://IP:port/** address shown
on the tablet in a browser, then enter the pairing code.

## Send to the tablet

- Drop files onto the browser page or click **Choose files**. Completed
  uploads go to **Downloads → Scriflow Wi-Fi Sharing**. Open them from the
  session’s received list or from **Files**. If a name already exists, Android
  saves the new file under a different name.
- Paste a URL in **Web link** and click **Send link**, or drag a web link from
  another page onto the sharing window. On the tablet, tap **Open link** beside
  the received address to open it in Scriflow.

## Send from the tablet

- Tap **Choose files…** in the sharing panel and select one or more files in
  Android’s file picker. After Scriflow prepares them, click **Download** in
  the other device’s browser.
- Paste a URL into the panel and tap **Send link**. For the current page in
  Scriflow’s browser, use **Send link over Wi-Fi…** in the browser menu to
  fill in the address. Click **Open link** on the other device to visit it.
- **Remove** withdraws an offered item from the browser list. Transfer
  individual files up to 1 GiB each, with up to 32 files and links offered from
  the tablet at a time. Preparing outgoing files uses temporary tablet storage.

## End the session

You can return to other app screens while sharing. Use **Stop sharing** in the
panel or notification to disconnect all browsers. Wi-Fi loss or an address
change ends the session. Each start displays a new address and code. Received
links and outgoing offers are session-only. Completed incoming files remain
in Downloads.

Use trusted Wi-Fi. The connection uses local HTTP without encryption and
requires a Wi-Fi IPv4 address. Guest networks that isolate devices can prevent
the browser from reaching the tablet. Use the displayed address and port,
including **http://**, and allow any browser or OS local-network prompt.
