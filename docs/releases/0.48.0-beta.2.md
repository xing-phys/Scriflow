# Scriflow 0.48.0-beta.2 — Consistent compact dialogs

- Chat history and the note/PDF table of contents now use the same rounded
  corners and circular close control as the open-note picker. Short history and
  outline lists size themselves to their contents.
- Other app dialogs, including bookshelf, Files, browser, chat and note menus,
  use matching rounded corners and compact close/cancel controls. Confirmation,
  save and editing actions remain available.
- Reading-settings and ebook panels also have rounded corners and a circular
  close control at the bottom right.

Host and browser regressions, Android lint and builds, and emulator interaction
checks cover dialog dismissal and confirmation, chat history, note/PDF contents
and reading settings. The physical MatePad and e-ink appearance remain untested.

VersionCode **128**. Notebook pages, the version-3 library catalog, ebooks,
backups and chat formats are unchanged from 0.48.0-beta.1. Older APKs still
cannot read a library catalog written in version 3. **0.33.2 remains Latest
stable.**
