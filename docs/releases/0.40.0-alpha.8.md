# Scriflow 0.40.0-alpha.8

The browser toolbox now matches the note toolbox's compact button size.
Android versionCode is **108**.

- Use **32 dp circular buttons** for browser toolbox actions and the dotted
  movable grip, with the same 20 dp symbols as the note toolbox.
- Keep action buttons at their fixed size, separated by 6 dp gaps. Wrap them
  into balanced rows when browsing beside a split note.
- Reduce the panel's maximum width to **400 dp**. Preserve the address field,
  tab counter, accessibility names, tooltips, collapse/drag and Zen behavior.
- Library and start-page actions keep their larger controls. Combining browser
  and writing tools remains a proposal for discussion.

The permanently signed APK and checksum are attached. Install as an update
without uninstalling. The APK remains approximately **228 MB**. Notebook, chat
and website archive formats are unchanged; **0.33.2** remains Latest stable.

Validation includes existing host/browser/PDF regressions, Android debug/release
lint/builds and emulator layout checks at true 4:3 portrait/landscape dimensions.
Check all browser toolbox buttons and the grip at 32 dp with no overlaps,
including beside a split note. Note-controller emulator checks use the existing
explicit debug software surface. Physical Huawei tablet/e-ink acceptance remains
pending.
