# Scriflow 0.40.0-alpha.12

PDF import previously followed the whole PDF object graph before reading,
rejected every encrypted file even when no opening password was required,
and stopped at 256 MiB. Android file managers could not offer Scriflow as a PDF
opener. This alpha fixes those paths and keeps the original PDF unchanged.

- **Open with / Share:** select Scriflow for a PDF in another app; it imports and
  opens a PDF notebook without launching another file picker.
- **Faster preparation:** import reads geometry, destinations and outlines;
  links and selected-page text load on demand. Images, font streams, attachment
  streams and annotation appearances stay out of the initial metadata read.
- **Readable encrypted PDFs:** files with an empty opening password work,
  including RC4 and AES-128/256. Annotated exports are unencrypted; the original
  encrypted source is preserved byte for byte.
- **Large files:** import and editable backup limits are 2 GiB, with copy
  progress, storage checks and fixed copy buffers. The 1,000-page limit remains.

Files with a nonempty opening password still need a copy with that password
removed. The first import still copies the original into private notebook
storage. Export uses the complete PDF loader to preserve source content and
can require more memory than metadata inspection.

Validation passed: the full host/browser/Markdown/AI/ink suite, 196 PDF engine
assertions, debug/release lint and builds, and APK manifest/signature verification.
The host PDF suite uses a 128 MiB heap and includes a valid 384 MiB scan.
An Android 10/API 29 emulator rendered ordinary and RC4/AES-encrypted PDFs,
resolved PDF Open with/Share intents, and imported the 384 MiB scan through the
actual Files app. The imported source's SHA-256 matched the original.

Physical MatePad Paper testing remains pending. Emulator results do not establish
Huawei handwriting behavior or performance for every complex PDF.

Android versionCode **112**. The APK uses the existing permanent signing key,
verified against `release-signing-certificate.sha256`. Notebook and backup data
formats are unchanged. This is an alpha prerelease; **0.33.2** remains Latest stable.

Download the signed APK and SHA-256 checksum from the
[GitHub release](https://github.com/xing-phys/Scriflow/releases/tag/v0.40.0-alpha.12).
