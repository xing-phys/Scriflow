# Scriflow 0.39.0-alpha.5

- The top-right clock/Wi-Fi/undo island now stays above a floating note in the
  AI main workspace, matching the top-left note-status island. Opening or
  raising a note re-presents the shared status bars above it.
- The toolbox and floating AI chats are restored above the status bars after
  that raise, preserving the intended order: main chat, floating notes, status
  bars, toolbox, floating chats.
- Native ink exclusions are refreshed for the re-presented layers. Writing
  resumes only when no pen contact or save error is active.

The APK is versionCode 100 and uses the permanent release signing certificate.
Notebook and chat archive formats are unchanged from alpha.4. Install as an
in-place update without uninstalling.

Host regressions, Android debug/release builds and lint, and permanent-signer
verification passed. No tablet was connected.
The host tests simulate window ordering; the physical status-bar stack, pen
input and floating-note controls still need verification on the target device.
