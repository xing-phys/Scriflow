Scriflow **0.35.0-alpha.5** (versionCode **78**) keeps Markdown in the clear page renderer throughout scrolling, zooming, fullscreen/Zen changes, writing and object manipulation.

The owner confirmed alpha.4 fixes figure dragging, but reported that navigation and Zen transitions still exposed the distorted native paper image. This release removes that page-rendering handoff.

### Changes

- Draw paper, PDF backgrounds, Markdown/figures and saved handwriting in one persistent ordinary View. When Markdown first becomes visible, keep the firmware surface above it for transparent live ink only. Retain its existing RGBA8888 format, native Z ordering, pen listener and AHW input.
- Use the firmware's transparent-color background API, also used by its stock notes engine. No subclass or replacement firmware code is included. Once enabled, the separation persists through scrolling, zooming, Zen entry/exit, writing, lasso, figure movement/resize/rotation, pending saves and surface recreation—even when Markdown moves offscreen.
- Render navigation and lasso scenes directly on the View canvas. Clear native trails once at navigation start; subsequent frames avoid native canvas posts and full-page bitmap copies. Release native paper/staging bitmaps in this mode. Add no paper work per pen MOVE.
- Preserve touch/focus passthrough, saved ink above figures, cross-page moves and foreground controls. Report rendering failures through existing recovery instead of silently falling back to distorted Markdown. Notes that never display Markdown retain their existing native paper path.
- Existing blocks need no re-creation or source edits. Editable data, vector appearances, exports, application ID, permanent signer and page format 8 are unchanged.

### Validation and remaining check

**252,206 JVM assertions in 84 suites and six browser cases pass**, alongside Android debug/release lint/build and permanent-signature verification. Production-method checks cover transparent native binding, absence of native page bitmap allocation, one native clear per navigation session, persistent paper eligibility during writing/navigation/Zen, multi-block/figure/lasso composition, pending saves and native surface recreation. Existing storage, input, geometry, PDF and offline Markdown regressions remain included.

**The new alpha.5 composition, optical quality and live writing on the transparent native surface still need physical tablet confirmation.** The firmware API behavior and stock notes usage were checked against the previously captured tablet framework; there is no connected tablet for this update. Host tests do not establish optical acceptance, stylus latency or e-ink refresh behavior. Target device: MatePad Paper HMW-W09, Android 10/API 29, firmware HMW-W09 2.1.0.222(C00E170R1P8).

### Install

Download `scriflow-0.35.0-alpha.5.apk` and its checksum. Install as an in-place update without uninstalling. Preserve editable backups. Page format 8 is unchanged from 0.34/0.35; APKs before 0.34 (including stable 0.33.2) cannot read notes edited in format 8. **0.33.2 remains Latest stable.**
