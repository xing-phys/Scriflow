# Scriflow 0.50.0-alpha.1

Wi-Fi Sharing lets the tablet exchange files and web links with a computer,
phone or tablet using a browser on the same Wi-Fi.

- Open **Settings → Wi-Fi Sharing → Share files and links…** or the Wi-Fi
  Sharing button in **Files**. Tap **Start sharing**, then enter the displayed
  address and pairing code in the other device’s browser.
- Drop files or a web link onto the page, or use **Choose files** and
  **Send link**. Files go to **Downloads → Scriflow Wi-Fi Sharing**. Tap a
  received link on the tablet to open it in Scriflow.
- To send to the other device, choose tablet files or paste a link in the
  sharing panel. In Scriflow’s browser menu, **Send link over Wi-Fi…** fills
  in the current page’s URL. The connection uses unencrypted local HTTP on
  trusted IPv4 Wi-Fi.
