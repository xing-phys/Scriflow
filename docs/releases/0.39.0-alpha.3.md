# Scriflow 0.39.0-alpha.3

- **AI chat** on the bookshelf opens a new or saved chat as an independent main
  workspace. It does not open the previous note or put it in the minimized
  notes tray.
- Closing or minimizing the main chat returns to the bookshelf. You can choose
  a note from the toolbox when needed; it opens as a floating window with its
  bottom-left options/move control and bottom-right minimize/resize control.
  Only notes you open and explicitly minimize appear in the notes tray.
- Activity recreation retains notes that were explicitly opened in the current
  workspace. Each note restores its own view state; starting a fresh chat from
  the bookshelf begins with no notes. Chats opened from within a notebook retain
  their existing behavior.

The APK is versionCode 98 and uses the permanent release signing certificate.
Notebook and chat archive formats are unchanged from alpha.2. Earlier APKs
cannot read chat archives from newly added provider profiles or restore the new
window layout; the earlier page-format-9 limitation still applies to individually
sized Markdown.

Host regressions, offline browser and PDF checks, Android builds and lint, and
release signing verification passed. No tablet was connected, so the independent
workspace, floating note controls, window layering and handwriting still need
verification on the target device.
