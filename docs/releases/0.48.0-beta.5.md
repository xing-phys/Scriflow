# Scriflow 0.48.0-beta.5 — Live reading controls

- Reading-view selections redraw notes and PDFs while the panel remains open.
  Handwriting stays paused until the panel closes; manual and semi-auto crop
  open their crop editor.
- Page-information export, reset and close actions align at the top right.
- In bookshelf thumbnail view, tap the preview to open an item and tap its name
  or opening time to show its action bar. The time has no redundant label.
  List-view item menus use uncircled three-dot icons.

Host, Android lint/build and emulator checks cover these interactions. Physical
MatePad and e-ink behavior remain untested.

Known issue: A new notebook can inherit a deleted notebook's saved workspace
position when the same notebook slot is reused. This predates this release.

VersionCode **131**. Notebook pages, the version-3 library catalog, ebooks,
backups and chat formats are unchanged from 0.48.0-beta.4. Older APKs still
cannot read a library catalog written in version 3. **0.33.2 remains Latest
stable.**
