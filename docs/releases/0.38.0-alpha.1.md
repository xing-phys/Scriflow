# Scriflow 0.38.0-alpha.1

- A refreshed black-and-white bookshelf, page manager and Settings, with
  outlined actions and icons. Lasso actions use the same circular icon size
  and spacing as figure and Markdown actions.
- Collapse nested headings with their arrows. Previous/next view controls appear
  only when a destination exists, at the lower right of the note or beside the
  minimize control inside a floating note. Choosing a page in the page overview
  now records the departing view.
- Floating AI chats appear above the toolbox, and the top status bars stay above
  split chat panels. The keyboard can cover the toolbox. PDF contrast updates
  while Reading view remains open, after replacement tiles finish rendering.
- Transfer screens retain their state across picker-induced orientation changes,
  a candidate fix for landscape PDF and figure import and PDF export.

The APK is versionCode 95 and uses the permanent release signing certificate.
No notebook or backup format is changed by this release. As in the previous
alpha, pages with individually sized Markdown use format 9, which older APKs
cannot read. The Android build and lint, host regressions, offline Markdown
browser checks and PDF checks passed.
No tablet was connected. Please verify the layouts, collapsible outline,
navigation buttons in normal and floating notes, keyboard/chat layers, live
contrast, and landscape import/export on the tablet; the landscape failure's
root cause is not yet confirmed.
