Scriflow 0.34.0-alpha.1 adds editable, offline Markdown blocks with typeset
mathematics. It promotes the tested dev.1 implementation with version and
documentation changes only, using Android versionCode **73** and the existing
permanent signing identity.

This is an **alpha prerelease** because the new Markdown feature has not yet
had physical tablet acceptance. **0.33.2 remains the latest stable release.**

### Changes

- Insert Markdown from the top-left action icons. Edit source inline and use
  nearby code/eye icons for source or rendered views. There is no Apply/Cancel
  footer or separate note-editing screen.
- Move, resize, rotate freely, copy/cut/delete and paste blocks using the figure
  controls. Drag across pages with edge scrolling and linked undo/redo. Tap
  outside to finish; copies retain editable source.
- Render CommonMark/GitHub-style Markdown, tables, task lists, footnotes,
  highlighted code, definition lists, Mermaid diagrams and common callouts
  offline, with bundled text/code/CJK fonts.
- Typeset inline/display LaTeX math, AMS/aligned equations, matrices, labels and
  references, physics/bra-ket and chemistry notation with local MathJax 4 SVG
  glyphs. This supports mathematical LaTeX, not a complete LaTeX document engine
  or every application's custom Markdown dialect.
- Keep editable source and two vector appearances. Native tiles render at the
  current zoom; PDF export retains text, fonts and math paths as vectors.
  Resizing scales the existing layout like a figure. External image URLs show
  an embedded-image placeholder; saved blocks require no network access.
- Save private typing-recovery drafts before compilation and retain them until
  successful page publication. Reopening can recover interrupted source edits.

### Storage compatibility

**Back up before updating. This is the first public release that writes page
format 8. Older APKs, including 0.33.2, cannot open pages edited by this release
or newly created editable backups. Do not downgrade over upgraded notes.**

Existing page versions 1–7 and older editable backups remain readable. Opening
a page does not rewrite it; its first edit retains the predecessor snapshot.
New `.inkbook` backups contain format-8 snapshots, even for unedited pages.
Keep independent, verified editable backups outside app storage before updating.
Uncommitted typing drafts are local recovery files and are not in notebook
backups until the block is successfully saved.

### Validation and limits

The implementation passes **250,255 JVM assertions in 71 suites**, **five
real-browser cases**, debug/release lint/builds and clean-checkout GitHub CI.
Coverage includes storage migration, backup/reopen, linked history, failed
publication/recovery, source-edit callbacks, rotated tile geometry, offline
math/diagrams/CJK, sanitized content with no script execution or external
requests, and real PDF exports at multiple angles. Poppler output was visually
inspected. Alpha promotion retains dev.1's compiled application code.

**This exact APK and the new Markdown interactions have not been tested on the
tablet.** Native WebView/PDF display, keyboard/stylus routing, floating/split
pane interaction, e-ink refresh and performance still need physical acceptance.
The owner's release authorization does not imply those checks passed.

Development targets **MatePad Paper HMW-W09, Android 10/API 29, firmware
HMW-W09 2.1.0.222(C00E170R1P8)**. Other hardware/firmware, battery life, optical
latency, physical cover sensing and very long sessions remain unverified.
The existing very-fast maximum-width erasing limitation remains.

Blocks accept up to 128 KiB of UTF-8 source and 4 MiB per vector appearance,
with a bounded layout height and existing per-page limits. Oversized content
should be split into blocks. Read the
[Markdown guide](https://github.com/xing-phys/Scriflow/blob/v0.34.0-alpha.1/docs/markdown-blocks.md)
for supported syntax, recovery and static-appearance behavior.

### Install/update

Download `scriflow-0.34.0-alpha.1.apk` and its adjacent `.apk.sha256` file.
Verify the checksum, then install as an **in-place update without uninstalling**.
The application ID remains `org.eink.inkprobe`. Uninstalling or clearing app
storage deletes private notes.

editable backups independently; a PDF export is a sharing copy, not an editable
