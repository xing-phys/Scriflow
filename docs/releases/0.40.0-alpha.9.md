# Scriflow 0.40.0-alpha.9

The browser now has **one movable toolbox** above floating and split notes.
Android versionCode is **109**.

- Before opening notes, show browser actions. Opening a note adds Pen, Eraser,
  Lasso, Add page, Outline and AI chat in a separate writing row in the same box.
- Hide that row when every note is minimized or closed. Keep browser actions
  in place, with one Notes button, one Zen button and one dotted grip.
- Collapse every control together. Retain 32 dp circular buttons, 6 dp spacing,
  address keyboard input, the compact 400 dp panel and remembered position.
- Share the note toolbox's window layer and native handwriting contact barriers
  and exclusions, so floating notes cannot shelter the controls.

The permanently signed APK and checksum are attached. Install as an update
without uninstalling. The APK remains approximately **228 MB**. Notebook, chat
and website archive formats are unchanged; **0.33.2** remains Latest stable.

Validation covers host/browser/PDF regressions, Android debug/release lint and
builds, and native emulator controller/layout checks at true 4:3 portrait and
landscape sizes. Emulator note checks use the explicit debug software surface;
physical Huawei handwriting, e-ink appearance and Eudic acceptance remain pending.
