Scriflow **0.37.0-alpha.2** (versionCode **90**) streamlines the floating AI chat interface.

## Updated controls

- Tap the toolbox AI icon for a tray containing **New chat (+)**, **History**, and minimized chats. New chat and History no longer appear inside floating windows. History is available even with no chat windows open, without creating a blank conversation.
- The header keeps the conversation title and Copy. The redundant settings shortcut is removed; use normal app Settings.
- Select models through the **model name at the bottom**, below the message field. It shows the friendly model name and opens the saved-model picker. Existing windows keep their own sessions; choosing a model opens a new chat and sets the toolbox default as before.
- Send with the **up-arrow icon on the right of the message field**, in the same rounded composer row. The control has no text label; it changes to a Stop square during generation, a Retry arrow for an interrupted question, or a Save icon after a storage error. Tooltips and accessibility labels identify the current action. Multiline input and Ctrl+Enter remain available.
- Existing move, resize, minimize, dock and close controls remain at the bottom corners. Model selection and the composer stay clear of these controls. Reopening history restores its existing owner; deleting a session closes any window that owns it.
