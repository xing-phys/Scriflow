Scriflow **0.35.0-alpha.1** adds PDF crop, single-page reading, Eudic word lookup
and adjustable contrast, using versionCode **74** and the existing permanent
signing identity. **0.33.2 remains the latest stable release.** This is an alpha
because the new reading interactions have not had physical tablet acceptance.

### Changes

- Open Reading view from the top-left action icons. Choose crop Off, Auto,
  Manual or Semi-auto. Tap opposite corners or drag edges; apply to this page,
  all pages, odd pages or even pages. Semi-auto detects inside your chosen area.
- Keep Continuous/Fit width as the default, or choose Single page/Fit page.
  Turn with the top-left arrows or horizontal swipes at whole-page size;
  pinch/pan still work within a single page. Zoomed drags pan without turning.
- Hold a finger on a PDF word to select it and open Eudic's floating dictionary.
  Nearby icons offer Copy and lookup. Scrolling, pinching, writing and stale
  callbacks cancel a pending hold. Active and inactive notes both support it.
- Increase PDF contrast to darken text edges/images on e-ink. Retain old tiles
  while replacement tones render, and keep the paused note visible beneath a
  transparent Eudic activity. Full stops release native resources normally.
- Preserve original PDF bytes, ink coordinates, PDF exports and existing sharp
  tile rendering. Figures and lasso drops respect the displayed crop. Include
  all offline Markdown functionality from 0.34.

### Requirements and storage

Word selection needs a PDF text layer; image-only scans are not OCRed. Eudic
must be installed and have any required floating-window permission. Scriflow
sends only the selected word through Eudic's documented local URL scheme and
does not gain Internet permission. Copy is explicit.

Crop, contrast and page mode are local display preferences, remembered per
notebook and excluded from editable backups. They do not change the PDF's
original margins/tones on export. Restore uses default reading preferences.

**Keep independent editable backups before updating.** Page format remains
**8**, introduced in 0.34. Existing formats 1–7 remain readable without rewriting
on open; edits and new `.inkbook` backups use format 8. APKs before 0.34,
including stable 0.33.2, cannot read those edited pages/new backups. Do not
downgrade over upgraded notes.

### Validation and limits

The implementation passes **252,121 JVM assertions in 77 suites** and **five
real-browser cases**. Automated validation covers source-coordinate crop/ink
invariants, single-page
zoom/swipes, atomic settings recovery, content detection/contrast, production
hold/crop/lifecycle callbacks, and real PDF word hits at 0°/90°/180°/270° with
nonzero crop boxes and embedded Unicode fonts. Existing storage, workspace,
writing, Markdown and export regressions and five real-browser cases pass,
along with debug/release lint/builds and APK/signature checks.

**This APK has not been tested on a connected tablet.** Eudic window/permission
behavior, physical finger/stylus routing, portrait/landscape, sleep/return,
e-ink refresh and sustained performance remain to be accepted on the device.
Development targets **MatePad Paper HMW-W09, Android 10/API 29, firmware
HMW-W09 2.1.0.222(C00E170R1P8)**. Other hardware/firmware, battery life, optical
latency, physical cover sensing and very long sessions remain unverified.
The existing very-fast maximum-width erasing limitation remains.

Read the [PDF reading guide](https://github.com/xing-phys/Scriflow/blob/v0.35.0-alpha.1/docs/pdf-reading.md)
for controls, crop behavior, dictionary requirements and storage details.

### Install/update

Download `scriflow-0.35.0-alpha.1.apk` and its adjacent `.apk.sha256` file.
Verify the checksum and install as an **in-place update without uninstalling**.
The application ID remains `org.eink.inkprobe`; uninstalling or clearing storage
deletes private notes. The APK uses the permanent signing certificate:

`2cc5db316df82fecc6085ff53e67cbd64f29b412f01e9a5c19bf4b34e3821709`

Only the signed APK and checksum are attached. A PDF export is a sharing copy;
keep editable `.inkbook` backups independently.
