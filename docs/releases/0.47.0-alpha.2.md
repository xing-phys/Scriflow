# Scriflow 0.47.0-alpha.2 — HTTP website access

- The browser can now open explicitly entered `http://` pages, including the
  reported Bitter Lesson address, and follow their links. Bookmarks, tabs,
  history and offline saves also support these pages.
- Addresses without a scheme continue to use HTTPS. An information icon beside
  an HTTP address explains that its connection is unencrypted. Microphone access
  remains restricted to HTTPS, and certificate errors are not bypassed.
- Offline copies remain isolated from the network. Capturing a secure page does
  not retrieve HTTP resources, and extension fetches cannot downgrade through a
  redirect. Secure-to-secure resource redirects continue to work.
- Includes the screenful tapping and per-notebook overlap setting from
  0.47.0-alpha.1 and the restored ebook navigation from 0.46.0-alpha.2.

Install the attached permanently signed APK over the existing app and verify
the attached SHA-256 checksum. VersionCode **126**. Notebook, ink, PDF, ebook,
backup and saved-page formats are unchanged. Reading preferences use version 5;
older APKs cannot read preference files updated by this version.

Host and emulator checks include loading the supplied live article, navigating
an HTTP link, capturing an HTTP page with an image, and reopening the saved page
after its server stops. Physical MatePad acceptance remains pending. The cause
of the reported unexpected EPUB return to the bookshelf is still unconfirmed.
