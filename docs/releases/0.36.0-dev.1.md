Scriflow **0.36.0-dev.1** (versionCode **82**) adds configurable floating **AI chat**.

### Use

1. Open **Settings → AI chat** from the time/battery/Wi-Fi pill.
2. Choose OpenAI, Anthropic, Google Gemini, DeepSeek, or a custom OpenAI-compatible HTTPS endpoint. Enter your API key, check the model and API base URL, and tap **Save AI settings**.
3. Tap the toolbox's **chat-bubble sparkle** to open the floating chat. Drag its title to move it or its lower-right handle to resize it.

Replies reuse the existing local Markdown renderer for headings, lists, tables, code, LaTeX/MathJax, Mermaid diagrams and multilingual text. Follow-up questions include the chat's previous turns. **Stop**, **Retry**, **Copy reply**, **New chat (+)** and **Close (×)** are available. Closing keeps the transcript and unsent draft. Each provider/endpoint/model has its own current conversation. Replies appear as complete messages for e-ink.

### Privacy and behavior

- Sending or retrying shares only this chat's text history and formatting instructions directly with the configured provider. Notebook pages, handwriting, figures and PDFs are not attached automatically. Provider usage charges and data policies apply.
- API keys are encrypted using Android Keystore and AES-GCM. Chat histories and drafts are unencrypted private files, separate from notebook backups. Remove saved key deletes the selected credential; New chat clears its conversation after confirmation.
- The APK adds `INTERNET` permission for explicitly submitted chat requests. Cleartext traffic is disabled and credential-bearing redirects are rejected. The Markdown WebView continues to block external requests and has no JavaScript bridge.
- Questions are saved before sending. Interrupted replies require an explicit Retry; no automatic retries occur. Native input barriers and exclusions protect the floating panel and software keyboard.
- This first version supports text chat, with one current conversation per provider/endpoint/model. It has no attachment picker or chat archive. See [AI chat documentation](https://github.com/xing-phys/Scriflow/blob/main/docs/ai-chat.md).

### Validation and remaining checks

**272,567 JVM assertions in 91 suites and eleven browser cases pass**, along with Android debug/release lint, builds and permanent-signature verification. AI checks exercise production provider protocols, HTTP failures/cancellation, atomic storage, retries, lifecycle callbacks and native contact/writer barriers without paid API requests. Browser checks cover Markdown/math/CJK/diagrams, follow-up retention, reset, sanitization and zero external requests; rendered chat was visually inspected.

**No tablet or live provider account was used for acceptance.** Physical keyboard/IME layout, drag/resize, stylus exclusions, e-ink appearance, long-chat memory use, and live provider requests still need confirmation on the MatePad. This is a **development prerelease**; **0.33.2 remains Latest stable**.

### Install

Download `scriflow-0.36.0-dev.1.apk` and its checksum. Install as an in-place update **without uninstalling**. The application ID and permanent signer are retained. Page/backup format **8** is unchanged. Preserve editable backups: APKs before 0.34, including stable 0.33.2, cannot read notes edited in format 8.

Compatibility remains Huawei MatePad Paper HMW-W09, Android 10/API 29, firmware `HMW-W09 2.1.0.222(C00E170R1P8)`. Other devices and firmware are unverified.
