Scriflow **0.35.0-alpha.8** (versionCode **81**) adds a **Region eraser** with a dashed-loop gesture.

### Use

1. Select Eraser, then tap its selected icon again to open eraser options.
2. Choose the dashed-loop eraser icon for **Region** mode.
3. Draw a region with the stylus and lift. The loop closes automatically and erases selected handwriting immediately.

Region mode follows the current Lasso selection rule: **whole strokes inside or intersecting the region are erased, including portions outside the loop.** Figures, Markdown blocks and original PDF content are retained. Choose the ordinary eraser icon to return to **Stroke** mode and its existing width slider. Region mode hides that slider. The mode is remembered across sessions and used by the M-Pencil Pen-to-Eraser shortcut.

### Behavior

- Reuse the native dashed lasso preview and cancellation-safe UP completion. No dashed outline is stored as handwriting; there is no selection-action menu or Done step.
- Support loops across visible pages, mapped through current zoom, pan and crop. Clip regions to visible paper so wholly hidden crop-margin and offscreen strokes are protected. Each affected page receives one undo entry, as with the normal eraser.
- Cancelled, degenerate and no-hit loops change no ink or undo history. Use the existing durable save, error recovery, undo and redo paths.
- Mode-button contacts pause native input until release. Accessibility changes use the same pause/layout/resume order; Back during a held mode button cancels its later click.
- Retain normal stroke erasing, finger navigation, ordinary Lasso selection, the latest floating controls and persistent clear-paper rendering.

### Validation

**272,413 JVM assertions in 88 suites and six browser cases pass**, with Android debug/release lint/build and permanent-signature checks. New checks execute production region clipping, cross-page/crop/zoom mapping, dashed pointer capture, cancellation and duplicate UP handling, tool mapping, remembered-mode callbacks and popup contact ordering. Real-file checks verify whole-stroke deletion, preservation of figures, no-hit history, undo/redo and reopen durability.

**There is no connected tablet for this update. The native dashed preview, mode-control placement and physical pen interaction still require confirmation on the MatePad.** Host tests establish the data and callback behavior, not optical appearance or latency.

Editable data, vector appearances, exports and page format 8 are unchanged.
