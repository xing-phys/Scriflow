# Scriflow 0.40.0-alpha.7

Online browsing and saved pages now share one note workspace. This alpha also
fixes pen/eraser settings appearing below floating notes, inaccessible split-note
controls and notes disappearing during a webpage dictionary lookup. Android
versionCode is **107**.

- **One browser note workspace:** open notes, the editing note, positions and
  minimized state follow you between online and saved-page screens and survive
  app restart. Closing/minimizing a note on an offline page updates the online
  screen when you return. Older screens cannot restore outdated window state.
  Notebook files remain independent from website archives and browser-data clearing.
- **Settings above notes:** pen thickness and eraser width/mode panels appear in
  front of floating notes. Their native handwriting exclusions and touch ownership
  remain in place. Fully leaving the screen retires transient settings panels.
- **Split controls:** the active split editor uses separate corner controls above
  its native surface, like floating notes. Position, Minimize, Close and pane-size
  actions remain reachable in all four split positions.
- **Floating dictionaries:** a webpage's selection menu can open Eudic without
  hiding the browser notes. Writing input pauses behind the overlay and resumes
  on the same surface when it closes. A fully covered/stopped browser still
  releases handwriting and reader resources.

The permanently signed APK and checksum are attached. Install as an update
without uninstalling. The APK remains approximately **228 MB**. Notebook, chat
and website archive formats are unchanged; **0.33.2** remains Latest stable.

Validation includes host/browser/PDF regressions, shared-workspace ownership and
restart cases, production note-control and dictionary lifecycle callbacks,
Android debug/release lint/builds and native emulator checks. The emulator checks
adjust real pen/eraser panels, use split window controls, transfer notes between
online/saved screens and compare the exact note pixels and surface identity
before, during and after a floating PROCESS_TEXT window. Native note-controller
checks use the explicit debug software surface; they do not verify Huawei's
handwriting driver. Physical tablet/Eudic/e-ink acceptance remains pending.

Toolbox consolidation is a design proposal for discussion; this build keeps the
existing browser and writing controls.
