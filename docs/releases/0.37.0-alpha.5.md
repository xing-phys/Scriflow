# Scriflow 0.37.0-alpha.5

This alpha makes the AI chat composer more compact, adds adjustable text sizes,
and fixes history-control and Markdown resize behavior.

- The options/move and minimize/resize grips, **+**, model picker and Send now
  share the message bar. Longer messages expand into a full-width editor above
  the controls. Attachment pills match the note's rounded status bars.
- **Settings → Text size** independently controls AI replies and Markdown
  blocks. AI replies default to 14 instead of 16. The Markdown setting applies
  to new blocks and to saved blocks when resized or rendered again from their
  source editor.
- Available Undo/Redo remains visible during pen, eraser and lasso work,
  including incidental finger contact and the writer's edit barriers. Navigation
  and other operations can still dismiss the controls.
- Markdown preview and vector rendering disable automatic browser text sizing;
  resize limits preserve text scale at the browser's supported width limits.

The APK uses Android versionCode 93 and the permanent release signer. Notebook,
backup and chat formats are unchanged. The full host suite reported 276,378
assertions in 120 suites; the offline browser renderer and PDF engine checks,
Android debug/release lint and builds, APK checksum and signer verification also
passed. No tablet was connected, so the new controls, IME behavior, handwriting
interaction, Markdown resize and e-ink rendering still need device testing.
