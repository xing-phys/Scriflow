Scriflow **0.35.0-alpha.4** (versionCode **77**) fixes the Markdown display transition when starting to drag a block and keeps the other blocks clear during the gesture.

The owner confirmed that alpha.3 makes stationary Markdown and the moving preview clear. They reported a brief distorted frame at drag start and distorted other blocks throughout dragging. This update addresses that remaining transition.

### Changes

- Draw the complete clear paper scene in the figure overlay from idle selection onward. Starting a drag, resize or rotation keeps that scene in place instead of exposing the native bitmap behind the selected block.
- Retain the stationary view when entering figure selection. Other visible Markdown blocks stay on the same clear View canvas throughout the gesture.
- Replace the selected block exactly once, including across pages and while a save is being restored. Compose saved handwriting above the figures; retain PDF backgrounds, page boundaries and exclusions for the toolbox, status islands and other note windows.
- Preserve native live writing, the ordinary figure-only preview path, existing blocks and storage format 8. No source edits or block recreation are required.
