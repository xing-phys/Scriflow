# Scriflow 0.40.0-alpha.6

The browser opens on its pinned homepage, shares the note status/Zen display,
and can open editable floating or split notes. Note selections also copy to the
Android clipboard for pasting into website editors. This continues the browser
alpha series with Android versionCode **106**.

- **Start on Home:** fresh bookshelf entries show pinned sites while retaining
  website tabs in Tabs. Explicit Open online links still open their requested
  page, and rotation/recreation retains the active page. Reuse an existing Home
  tab; at the tab limit Home does not discard a website.
- **Shared status:** time, battery and Wi-Fi remain at the screen's top-right
  when browser tools collapse. Zen uses the same small rounded clock tab as
  notes; tap it or press Back to exit.
- **Notes beside websites:** use the overlapping-window icon in the browser
  toolbox. The existing native note editor supports writing, lasso and figures.
  The note corner menu offers Floating, Left, Right, Top and Bottom positions,
  resizing, minimizing and closing. Docked notes reserve space so the website
  reflows beside them; minimized notes can be reopened from Notes.
- **PNG clipboard:** Copy ink and Copy/Cut figure retain the internal note copy
  and also place a PNG on Android's clipboard. Wait for **Copied as image**,
  then hold an editable website field and choose **Paste**. Website editors that
  accept images can attach and send it using their own Send button. Markdown
  copies provide source text. Clipboard images use bounded private temporary
  files and individual read-only grants; no automatic website submission occurs.
- **Paul Graham saving:** capture the browser's parsed CSS rules so legacy HTML
  comment wrappers on mobile pages do not abort saving. An unreadable inline
  style becomes a capture warning instead of losing the entire page.

The permanent-key signed APK and checksum are attached. Install as an update
without uninstalling. The APK remains approximately **228 MB**. Notebook, chat
and website archive formats are unchanged; **0.33.2** remains Latest stable.

Validation covers host/browser/PDF regressions, native note activation and
minimization callbacks, four split positions at portrait/landscape 4:3 sizes,
CSS-comment capture and cold offline math/fonts/images/security checks, and
Android debug/release lint/builds. Native emulator checks exercise Home, shared
status/Zen, floating and docked note controllers, minimizing/reopening, PNG
clipboard pasting into a real Gecko contenteditable, and cold offline reopening
of the reported article with section history. Emulator note checks explicitly
use a debug-only software surface and do not validate Huawei handwriting.

Physical tablet pen/e-ink acceptance, Eudic on the actual tablet and authenticated
ChatGPT attachment handling remain pending. A website must accept pasted images;
file-picker uploads and file downloads are outside this build.
