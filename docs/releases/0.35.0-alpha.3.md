Scriflow **0.35.0-alpha.3** (versionCode **76**) changes the **stationary Markdown display path itself** to the ordinary View/PopupWindow composition used by the clear drag preview.

The owner confirmed that alpha.2 looked unchanged at rest. Its published APK was the correct signed build, but the raster-mode change was ineffective. Alpha.3 adds a separate resting presentation; it does not repeat that raster-only adjustment.

### Changes

- Draw paper, figures/Markdown and saved handwriting together directly in a regular View canvas while a note with visible Markdown is at rest. This covers the native bitmap's distorted glyphs and keeps annotations above figures.
- Retain the complete native frame underneath. Hide the added view before pen input, navigation, modal editing and lasso manipulation; show it only after native pen/eraser/lasso commits are settled. Preserve the direct native live-writing path, without work per pen MOVE.
- Keep the view untouchable and unfocusable. Protect the toolbox, status islands, other notes, tray and dictionary selection regions. Reuse its window below figure controls, skip redraws for unchanged status/clock bounds, and close it with the editor.
- Fall back to the intact native frame if the extra View cannot draw. Existing blocks need no source edits or re-creation. Source, vector appearances, exports and storage format 8 are unchanged.
- Retain all PDF reading controls and other features of alpha.2.
