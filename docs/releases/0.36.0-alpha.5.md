Scriflow **0.36.0-alpha.5** (versionCode **87**) simplifies AI model settings.

## What changed

- **A direct model list:** enter the API URL and key, tap **Fetch available models**, and models appear below as names with checkboxes and settings gears. Check the ones you want and **Save AI settings**. The Model ID field, Add selected dialog and Manage saved models button are removed.
- **Parameters behind the gear:** context/input limits, maximum output, reply budget, image support and thinking options are automatically filled. Open a model's gear to inspect or edit them. **Apply**, then **Save AI settings**, keeps changes. **Use fetched defaults** resets the form.
- **Edits survive refresh:** overrides persist across save/reopen and later fetches. Refresh updates the underlying defaults, so reset uses the latest fetched values. Unchecked models remain cached with their parameters; unchecking removes them from the chat picker without deleting their sessions.
- **A single save:** the connection, encrypted key, catalog and selected profiles are published together. You can save only the connection before selecting models. Existing profiles remain available offline. The chat model picker uses compact names too.

## Storage and requests

Existing metadata sources, provider protocols and explicit Send behavior are retained. The main list hides technical details; model dialogs show the source and check date. Missing metadata uses provider defaults until optionally configured by hand. The catalog caches up to 1,000 rows, with 64 checked models per endpoint.

Catalogs, fetched defaults and overrides are private local data outside notebook backups. API keys remain encrypted separately from model records. No automatic chat requests are introduced. **Notebook/backup format 8 and chat archive format are unchanged.**
