# Scriflow 0.43.0-alpha.1 — Wi-Fi screen cast

Share Scriflow in a browser on your Mac, phone or tablet connected to the same
Wi-Fi, with a password set on the tablet. No viewer app or Internet service
is required. Multiple browsers can watch independently.

1. Open **Settings → Screen cast → Screen cast to a browser…**.
2. Set an **8–128 character password**, or generate one and remember it.
3. Tap **Start casting** and approve Android's screen-capture prompt.
4. Open the complete **http://IP:port/** address shown on the tablet in the
   other device's browser and enter the password.
5. Return to a note, PDF, ebook or browser page on the tablet to share it.

The viewer is read-only, with portrait/landscape support and a full-screen
button where available. **Stop casting** in the panel or Android notification
disconnects everyone. Settings and cast controls stay private; leaving
Scriflow or losing app focus clears the feed. Display off/lock, Wi-Fi loss
or an address change ends the session. Passwords, sessions and screen images
remain in memory and are not saved. Existing notebook/backup formats are unchanged.

**Use trusted Wi-Fi.** The local HTTP connection is not encrypted; the password
blocks unauthenticated viewing but does not protect against intercepted network
traffic. Guest Wi-Fi/client isolation may block connections. IPv4 Wi-Fi is
required; this release has no audio, remote control, recording, IPv6-only or
hotspot-hosting support. See the [screen cast guide](https://github.com/xing-phys/Scriflow/blob/v0.43.0-alpha.1/docs/screen-cast.md).

Validation includes **78** real-socket access-control/frame-ownership checks,
**19** desktop/phone Chromium viewer checks and **17** Android 10 emulator
capture/lifecycle checks, the full existing host/browser/AI/PDF regressions,
Android lint/builds, and the pinned permanent release signer. Emulator HTTP checks
reach the actual Wi-Fi-bound server using adb, rather than a physical LAN.
Huawei native live ink, e-ink performance, Safari and actual tablet-to-Mac
Wi-Fi acceptance remain pending owner testing.

Install the attached permanently signed APK to update the existing app.
The attached SHA-256 file verifies its bytes. VersionCode **117**.
