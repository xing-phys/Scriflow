# Scriflow 0.39.0-alpha.4

- The writable floating note's bottom-left options/move and bottom-right
  minimize/resize buttons now use small windows above the native writing
  surface. View-history buttons use the same approach. The controls follow the
  note as it moves, resizes, or becomes the active editor.
- The lasso action bar now uses the active floating note's window layer in an
  AI-main workspace. Its bounds also protect the actions from native ink input.
  Copy, cut, delete, duplicate, move, export, and append-to-AI retain their
  existing actions.

The APK is versionCode 99 and uses the permanent release signing certificate.
Notebook and chat archive formats are unchanged from alpha.3. Earlier APKs
cannot read chat archives from newly added provider profiles or restore the new
window layout; the earlier page-format-9 limitation still applies to individually
sized Markdown.

Host regressions, offline browser and PDF checks, Android builds and lint, and
release signing verification passed. No tablet was connected. The host tests
simulate Android window ordering; actual corner controls, lasso actions, pen
input, moving and resizing still need verification on the target device.
