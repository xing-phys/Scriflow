# Scriflow 0.37.0-alpha.6

- Select a Markdown block and tap **A with arrows** to change its rendered
  preview font size. The choice stays with the block; raw text keeps its own
  size. **Settings → Text size → Markdown blocks** sets the default for new
  rendered and raw blocks and the source editor.
  Earlier blocks did not record their font sizes, so their first re-render uses
  the former defaults (18 preview, 14 source); the A icon can adjust the preview.
- Keep the saved Markdown at its original scale while a correctly initialized
  browser preview warms. Reflow the preview with coalesced updates, avoid
  repainting the full note for each drag event, and reuse the warm preview for
  vector compilation on release. Fix a multiline conversion defect that could
  squeeze raw source into a single line.
- Center pending AI attachment labels vertically inside their pills. Selection
  actions wrap in narrow panes so the new Markdown control remains reachable.

**Compatibility:** pages with newly rendered or individually sized Markdown
use page format 9. Older APKs cannot read those pages or backups containing
them. Pages without the new font metadata continue to use format 8. Existing
pages are read without rewriting; the exact previous page is retained when a
page is migrated. Keep an independent backup before updating.

The APK is versionCode 94 and uses the permanent release signing certificate.
Host checks passed 276,426 reported assertions across 124 suites. Real-browser,
PDF and Android build/lint checks also cover the new paths; the tablet was not
connected. Resize fluency, text scale, the font picker,
attachment alignment and e-ink behavior still require physical verification.
