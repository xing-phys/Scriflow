# Scriflow 0.44.0-alpha.1 — Reading views and sign-in windows

This prerelease fixes ebook layouts and contents, adds reader gestures and a
two-page view for PDF notebooks and notes, and repairs a browser popup handoff.

- **EPUB, MOBI and other reflowable books:** Two columns now show a real spread
  in portrait or landscape. Two columns use page turns; continuous scrolling
  uses one column. A finger tap on the right or bottom half advances, and a tap
  in the upper-left quarter goes back. Links, selection and zoomed fixed-page
  panning keep their normal behavior.
- **Book contents:** Parent headings expand and collapse. The current heading is
  emphasized and its ancestors are opened, matching the notebook outline's
  navigation behavior.
- **PDF and note reading:** Choose **Reading view → Two pages**. Pages 1–2,
  3–4 and so on appear together; the final odd page remains accessible. At
  whole-page fit, arrows or a horizontal swipe turn a spread. Pinch and pan,
  per-page writing, crop, links and the floating reader remain available.
- **Browser sign-in:** Sign-in windows retain their connection to the page
  that opened them and return focus when they close. Popup requests remain
  HTTPS-only, and offline pages remain isolated from the network.

The host regressions, 44 real-browser ebook assertions, 21 Android Gecko book
checks and seven Android ebook-control checks pass. Emulator checks also showed
a PDF and a note page together, reopening the spread, and swiping to the final
odd page. Synthetic Android popup checks tested a direct window and an initially
blank window navigating to a separate HTTPS origin and returning its result.
They did not use a Google account or test X. Physical MatePad Paper e-ink,
stylus input on both pages, real book layouts and X/Google sign-in still need
owner testing. Beta and release-candidate promotion should follow that testing.

Install the attached permanently signed APK over the existing app; the SHA-256
file verifies its bytes. VersionCode **119**. Notebook, PDF, ink and backup
formats are unchanged. Reading-view preferences now use a newer format; older
app versions do not understand newly written view settings. **0.33.2 remains
Latest stable.**
