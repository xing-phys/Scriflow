# Scriflow 0.45.0-alpha.2 — File manager controls and types

- File-manager icons are centered, and routine navigation, selection and paste
  controls use compact icons with accessible names and tooltips.
- Tap Search to show the search field in the navigation row; the close icon
  returns to browsing. The routine item-count footer is hidden, while progress,
  errors and listing-limit notices remain visible when needed.
- Folder icons and file-type badges distinguish PDFs, EPUBs and other formats
  in both list and thumbnail views. Actual image/PDF previews retain a type badge.

The bookshelf's existing PDF and ebook import shortcuts remain available; they
use Android's document picker, including installed document providers. PDFs and
supported ebooks on shared storage can also be opened through Files.

Install the attached permanently signed APK over the existing app and verify
the attached SHA-256 checksum. VersionCode **122**. Notebook, ink, PDF, backup
and saved-page formats are unchanged. Host regressions, Android lint and emulator
UI checks do not establish physical MatePad touch behavior or e-ink appearance;
physical tablet acceptance remains pending. **0.33.2 remains Latest stable.**
