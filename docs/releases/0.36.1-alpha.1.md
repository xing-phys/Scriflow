Scriflow **0.36.1-alpha.1** (versionCode **88**) corrects the floating AI window frame during resizing.

## Resize correction

- Give the popup a separate outer frame. Its contents are inset and clipped, and four solid black strips draw inside the actual viewport after the contents. The right and bottom edges no longer depend on a foreground drawable attached to the chat layout.
- Enable window clipping and remove the extra transparent background wrapper. Redraw the frame after the window's new size is applied, and use its measured bounds for native pen exclusions.
- Keep the top-left corner anchored during bottom-right resizing and retain window position/size preferences.

The previous automated checks covered requested coordinates but did not check the painted borders. New tests execute the production frame drawing and scan all four edges after growth and shrink, including short/narrow viewports and oversized content. **The owner's tablet is unavailable, so this does not claim physical reproduction or verification of Huawei's compositor behavior.**

## Version numbering

This fix increments PATCH: **0.36.0 → 0.36.1**. The alpha suffix marks its first test candidate. The project now documents patch bumps for bug-fix tasks, minor bumps for new-feature tasks, and alpha/beta/rc numbers for iterations of the same candidate. Android versionCode remains a separate increasing install counter. Existing published tags are unchanged.
