# Scriflow 0.46.0-alpha.2 — Ebook chapter transitions

- Restore the previous ebook controls: tapping the book title returns to the
  bookshelf, and Android Back dismisses a panel or selection before leaving.
- Fix a reproducible error when a delayed selection callback runs after an EPUB
  chapter has been detached. The stale callback cannot clear a selection in the
  newly opened chapter.
- Exercise repeated real GeckoView taps and swipes across chapter boundaries,
  and check that no reader JavaScript errors occur.

The reported unexpected return to the bookshelf has not been reproduced on
the emulator. Without logs from the tablet, this fix cannot be confirmed as the
cause of that return; physical testing remains necessary.
