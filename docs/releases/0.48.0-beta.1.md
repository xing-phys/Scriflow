# Scriflow 0.48.0-beta.1 — Bookshelf and file workflows

- Bookshelf, new-folder and Trash buttons share the existing shortcut row.
  Create nested folders, move notebooks and ebooks using full folder paths, and
  navigate folders when opening a split or floating note. The note picker has
  rounded corners and a compact circular close button; the open-note icon now
  depicts a notebook with a plus sign.
- PDF, ebook, backup, figure and font imports and export destinations use
  Scriflow's Files browser. Saving creates a new file and does not overwrite an
  existing name. Files access permission and mounted shared storage are required;
  Android cloud document providers are not included in this picker.
- Lasso export offers SVG, PNG, JPEG, WebP and PDF in a small menu beside the
  selection, then opens Files for the destination.

Host regressions, Android debug/release lint and builds, and 17 existing Files
UI checks pass. Emulator checks also cover nested shelf and floating-note
navigation, PDF import, backup export and destination name collisions.
Native selected-ink rendering requires the Huawei APIs absent from the emulator.

This is a beta prerelease at the owner's request. Automated checks and the
Android emulator do not establish physical MatePad, stylus or e-ink acceptance;
the new interactions and earlier alpha changes still need tablet testing.
VersionCode **127**. Library catalog version 3 reads versions 1 and 2, but older
APKs cannot read a catalog written by this release. Notebook page and editable
backup formats are unchanged. **0.33.2 remains Latest stable.**
