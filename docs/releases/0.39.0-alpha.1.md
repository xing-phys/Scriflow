# Scriflow 0.39.0-alpha.1

- The table of contents opens with other branches collapsed, the current
  heading in bold, and its ancestors expanded. The bookshelf and Settings use
  the same top-right time, Wi-Fi and battery control as the notebook. Folder
  and Trash locations appear as selected tabs.
- Hold a notebook on the bookshelf or in Trash to enter selection mode; select
  more or use **Select all**. Move selected notebooks to a folder or Trash, or
  restore them from Trash. Individual permanent deletion and folder actions
  remain available from their **⋮** menus.
- Reading view appears above the toolbox. Chat composer and note-window corner
  controls are smaller and better spaced.
- Choose **Position → Main window** from a chat's bottom-left menu to make chat
  the main workspace and show notes as floating windows. At least one note stays
  open; closing or minimizing the main chat restores the note workspace.
- Settings can hold multiple named AI provider profiles, including multiple
  custom providers. Each has its own URL, models and encrypted API key. An
  existing key is not reused when changing its endpoint without re-entering it.

The APK is versionCode 96 and uses the permanent release signing certificate.
Notebook formats are unchanged. Chats saved using newly added provider profiles
have a header that earlier APKs cannot read; earlier APKs also cannot restore
the new workspace layout. Legacy-provider chats and notebook files retain their
existing formats. The earlier page-format-9 compatibility limitation still
applies to individually sized Markdown.

Host regressions, offline browser and PDF checks, Android builds and lint, and
release signing verification passed. No tablet was connected. Please verify the
e-ink layouts, selection, Reading view and main-chat window layers, controls,
and handwriting on the target device.
