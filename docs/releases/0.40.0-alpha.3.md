# Scriflow 0.40.0-alpha.3

The browser now has a pinned start page, bookmark collections, tabs, searchable
history and browser-data settings. This continues the 0.40 browser alpha series
with Android versionCode **103**.

- **Start page:** a native search/address field, pinned website cards and quick
  access to Bookmarks, History, Tabs and Browser data. Hold shortcuts to edit,
  reorder or unpin them. Deleted starter shortcuts stay deleted. Home returns
  here while retaining the current page. No shortcut/favicon requests occur
  until a website is opened.
- **Bookmarks:** add/edit website names and addresses, organize links into named
  collections, search, move, pin and delete. Removing a collection keeps its
  bookmarks in Unsorted. Bookmarks and offline saved pages remain independent.
- **Tabs:** open, switch and close up to 12 tabs. Live tabs have independent
  navigation; destinations and selection survive restarts. The active tab's
  history restores across screen recreation. User-initiated new-window links
  open another tab; automatic popups remain blocked.
- **History and search:** find/reopen recent pages or remove individual entries.
  Both address fields accept searches; choose DuckDuckGo, Google or Bing in
  Browser data. There are no automatic search suggestions. The menu also offers
  copying/sharing addresses and opening another installed browser.
- **Browser data:** choose cookie policy, inspect cookie-domain counts, clear
  one host, or independently select cache, cookies/site storage and history.
  Cache-only clearing keeps login cookies. Clearing closes website sessions and
  invalidates restorable tabs, including older Android state snapshots.
  Bookmarks, pinned sites, offline copies and notebooks are preserved.

The permanently signed APK and checksum are attached. Install as an in-place
update without uninstalling. It retains GeckoView 160, the floating toolbox,
clock-only Zen, math rendering, and existing HTML/MHTML offline copies. The ARM
APK is approximately **228 MB**. Notebook and chat formats are unchanged.

Validation: **278,010 reported JVM assertions across 150 suites**, sixteen
Markdown browser cases, fourteen legacy archive checks and fifty HTML
capture/protocol checks; Android debug/release lint/builds and permanent signer,
manifest, private diagnostics and asset verification. Android emulator tests
exercised real cookies across process restart, cache-only and per-host/global
clearing, preservation of bookmark bytes and offline files, shutdown of two
loaded tabs, and rejection of a pre-clear Android state snapshot. Native UI
checks created a bookmark collection, assigned/pinned/edited a bookmark, returned
to the updated start page and changed cookie policy. Live tab checks switched
between GitHub and the reported page with all 168 formulas, recreated the screen
and restored tabs after a cold process restart.

Physical Huawei tablet layout, touch and e-ink acceptance remain pending.
0.33.2 remains Latest stable.
