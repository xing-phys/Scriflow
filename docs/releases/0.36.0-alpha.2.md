Scriflow **0.36.0-alpha.2** (versionCode **84**) fixes AI window resizing and adds model discovery and selected content in chat.

### Changes

- **Resize:** drag the lower-right handle. The top and left edges stay fixed; right/bottom edges remain on screen. A foreground border stays visible above the window contents.
- **Models:** enter your provider, API URL and API key in **Settings → AI chat**, then tap **Fetch available models**. Select an ID from the model field's dropdown and save. Fetching also reuses an existing saved key when the field is blank. Manual IDs remain supported for endpoints without model listing.
- **Selected content:** use the chat-bubble sparkle beside lasso actions or a selected image/Markdown block to append it to the AI draft. Markdown appends as original source; selected handwriting and images become bounded PNG attachments. Remove unwanted **Ink/Image ×** chips, add a question, and press **Send**. Appending opens the chat but never sends automatically or changes the notebook/clipboard.
- Sent images appear in chat and remain in follow-up context. Unsent image drafts survive reopening. Choose a model supporting image input to analyze ink/images; the returned catalog may also include non-chat models.

### Data and compatibility

Send shares the chat text and selected attachment history directly with your configured provider; its data policies and charges apply. Model fetching sends only an authenticated catalog request. Notebook content is not included unless explicitly pasted or appended. API keys stay encrypted using Android Keystore; the renderer cannot access them or fetch remote content.

Up to four PNG images per message, 1 MiB each and 2048 pixels per edge; larger images are downscaled. Total chat image data is bounded to 8 MiB alongside the existing text limits. Chat files now write format 2 and read earlier format 1. Earlier AI APKs cannot read newly saved chats; **notebook/backup format 8 is unchanged**.

### Validation

**272,746 JVM assertions in 92 suites and fourteen real-browser cases pass**, plus Android debug/release lint/build checks. Production resize-grip tests verify anchored placement, right/bottom bounds, persistence and border invalidation. AI tests cover provider model catalogs, pagination, errors/cancellation, image request formats, v1 chat compatibility, attachment recovery and appending while a request runs. Browser checks cover image previews/follow-up retention, rejected external image URLs and zero external renderer requests.

**Physical tablet and live-account/model/vision checks follow this alpha release.** No new optical e-ink, stylus, keyboard or provider-account acceptance is claimed.
