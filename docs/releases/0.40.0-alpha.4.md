# Scriflow 0.40.0-alpha.4

Browser controls now use familiar icons with consistent spacing, and tabs have
a clearer layout. This refines the ongoing browser alpha series with Android
versionCode **104**.

- **Icon controls:** Home, Bookmarks, Tabs, Save, Saved websites and the other
  browser actions use centered monochrome symbols with tooltips and accessibility
  names. Action targets are at least 48 dp. The tab icon shows the open-tab count.
- **Responsive toolbox:** actions wrap into balanced rows on narrow screens.
  The address field, header actions and time/battery/Wi-Fi island have separate
  space; no action is hidden beyond a sideways-scrolling toolbar.
- **Tabs:** separate title and address lines, a checkmark and stronger outline
  for the current tab, and spaced close controls. Long titles are shortened so
  the close button keeps its own touch target. The plus icon creates a new tab.
- **Start page and library screens:** aligned pinned-site cards, a matching Add
  shortcut tile, icon shortcuts, and consistently spaced bookmark, history and
  browser-data controls. Destructive data actions retain explicit confirmations.

The permanently signed APK and checksum are attached. Install as an in-place
update without uninstalling. GeckoView, bookmarks, cookies, offline copies,
notebooks and the existing movable/collapsible controls and clock-only Zen mode
are retained. Notebook, chat and website archive formats are unchanged. The ARM
APK remains approximately **228 MB**.

Validation: existing host/browser/PDF regressions, Android debug/release lint
and builds, APK contents and the permanent signing certificate. Native Android
emulator checks cover icon touch targets and overlap, the tab picker with a long
page title, bookmark/history/data navigation, collapse and Zen, and saving and
reopening the reported math page with offline section Back/Forward. The online
page still renders all 168 formulas. Layout checks include tablet and 320 dp
widths, a landscape viewport and larger system text.

Physical Huawei tablet touch, layout and e-ink acceptance remain pending.
0.33.2 remains Latest stable.

See [Browser and offline websites](https://github.com/xing-phys/Scriflow/blob/main/docs/browser.md)
for the icon guide and browser behavior.
