# Scriflow 0.40.0-alpha.2

This browser update bundles the current Firefox engine for modern websites and
math, adds movable controls and clock-only Zen, and supports offline section
Back/Forward. It continues the 0.40 browser alpha series (versionCode **102**).

- **Website compatibility:** GeckoView **160.0.20261104181552** replaces firmware
  WebView for live browsing. A GitHub repository now loads without the old
  JavaScript syntax errors; the reported Quarto page renders all **168 formulas**
  in the Android app. No user-agent impersonation or page-specific patch is used.
- **Floating controls:** tap the dotted button to collapse/expand every app bar,
  including URL, navigation, Reload, Save and status. Drag it in either state.
  Position and collapse state are remembered; the page retains its full area.
- **Zen:** the fullscreen-corners icon leaves only a top-right seconds clock.
  Tap the clock or press Back to restore the previous control state. Hidden
  and background clock callbacks stop.
- **Offline navigation:** Back/Forward traverse section links and restore scroll
  positions, including across screen recreation. External links require an
  explicit online opening; offline history stays inside the selected archive.
- **Offline capture:** new saves use self-contained HTML with rendered math,
  embedded fonts, styles and images. Missing resources are reported. Existing
  MHTML saves remain readable. Page scripts and network loads are disabled
  offline; new saves also carry a restrictive content security policy.

Install the permanently signed APK as an in-place update without uninstalling.
The engine increases download size; the release contains compressed ARM builds
and excludes emulator libraries. Its separate website profile may require
signing into sites again. Notebook/chat formats remain compatible. The
HTTPS-only policy is retained. Website snapshots use NWS2 metadata for new
HTML saves while retaining NWS1/MHTML reading.

Validated: **277,955 reported JVM assertions across 148 suites**, sixteen offline
Markdown browser cases, fourteen legacy archive checks, forty-seven HTML
capture checks, debug/release lint and builds, packaged permissions/components,
asset checksums and permanent-signer verification. Android API-29 emulator
checks exercised the production browser on GitHub and the reported math page,
then saved and reopened the math page with Wi-Fi/data disabled, checked section
scroll positions through Back/Forward and Activity recreation, and exercised
Zen and toolbox dragging. The saved file contains all 168 rendered formulas.
A legacy MHTML fixture also reopened and traversed sections in the Android app
with networking disabled.

Physical tablet touch/zoom, layout and e-ink refresh still need owner testing.
Captures cover one page and loaded resources; interactive services, streaming
media and inaccessible frames may need the online original. The signed APK and
checksum are attached; 0.33.2 remains Latest stable.

See [Browser and offline websites](https://github.com/xing-phys/Scriflow/blob/main/docs/browser.md).
