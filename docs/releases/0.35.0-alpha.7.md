Scriflow **0.35.0-alpha.7** (versionCode **80**) places the top-left action circles to the right of the note bar.

### Changes

- Open the action circles to the right, with the existing small gaps. The three dots disappear while the actions are open and the note bar becomes shorter. On narrow panes, additional rows remain in the right-side lane.
- Remove the redundant Choose a figure action and its list dialog. Tap a figure directly to select it for moving, resizing, rotation and nearby copy/cut/delete actions. Insert figure and conditional Paste figure remain in the menu.
- Choosing a function, interacting with the page or pressing Back closes the actions and restores the three dots and normal bar width.
- Retain the separate Undo/Redo and toolbox circles, transparent clock background, persistent clear paper/Markdown rendering, existing functions and visibility rules.

### Validation

**252,204 JVM assertions in 84 suites and six browser cases pass**, along with Android debug/release lint/build and permanent-signature checks. Existing menu dispatch, narrow-pane placement, popup failure handling, direct figure selection, history/Zen and rendering regressions remain included. Physical tablet placement is not verified in this update.

### Install

Download `scriflow-0.35.0-alpha.7.apk` and its checksum. Install as an in-place update without uninstalling. The application ID and permanent signer are retained. Editable data, vector appearances, exports and page format 8 are unchanged. Preserve editable backups; APKs before 0.34 (including stable 0.33.2) cannot read notes edited in format 8. **0.33.2 remains Latest stable.**
