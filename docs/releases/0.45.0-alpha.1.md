# Scriflow 0.45.0-alpha.1 — Collections and browser home

- Settings has clearer sections, compact choices and more space between controls.
  Time, battery and Wi-Fi use a consistent top-right position across the app's
  headers and note, ebook, browser and AI workspaces.
- Files and Saved websites each offer remembered list and thumbnail views.
  Lists use one column in portrait and two in landscape. File cards preview
  local images and PDFs; unsupported or unavailable previews show type icons.
  Saved-page cards use locally cached browser previews when available.
- Browser Home displays open tabs alongside pinned websites. Smaller cards and
  separate list/thumbnail switches make both collections easier to browse.
  Open or close tabs from Home, and use the expanded shortcut row to reach a
  new tab, saved pages, bookmarks, history and other destinations.

Install the attached permanently signed APK over the existing app and verify
the attached SHA-256 checksum. VersionCode **121**. Notebook, ink, PDF, backup
and saved-page formats are unchanged. Browser preview caches are disposable;
opening a collection never fetches pages or favicons to create thumbnails.
