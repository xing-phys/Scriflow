# Scriflow 0.40.0-alpha.11

Website voice input can request the microphone, browser background work is
reduced, and all note workspaces share writing settings. Android versionCode
is **111**.

- Ask for Android microphone permission on first online Browser entry. Each
  foreground HTTPS document also asks before recording. New documents reset
  consent; offline pages and camera requests remain denied. This enables
  website voice input without adding native note/AI transcription.
- Reduce periodic session snapshots from once a second to once per 15 seconds,
  while retaining navigation/visibility checkpoints. Coalesce duplicate page
  previews, cancel completed capture timeouts, suspend hidden-page bridge timers,
  and back off failed reconnects. Keep normal page rendering and interaction.
- Place pen/eraser options, the note tray and note picker near their actual
  buttons, using the full workspace even when the active note is small or split.
- Share pen thickness, eraser size and stroke/region eraser mode across ordinary
  notes, AI chat and online/offline browser notes. Migrate existing notebook
  preferences and refresh retained editors when returning from another screen.

Install the permanently signed APK as an update without uninstalling. The APK
and SHA-256 checksum are attached. Notebook, chat and website archive formats
are unchanged; **0.33.2** remains Latest stable.

Validation covers host/browser regressions, Android debug/release lint/builds,
native microphone consent and live audio-track checks, and popup placement in
4:3 portrait and landscape. Emulator note checks use the debug software writing
surface. Physical Huawei handwriting, real
microphone quality and battery-life measurements remain pending tablet testing.
