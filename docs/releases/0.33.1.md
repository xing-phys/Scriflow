Scriflow 0.33.1 improves floating-note controls and rendering efficiency. It
includes all changes through 0.33.1-dev.9 with the existing application ID,
permanent signing identity and stored data formats.

### Changes

- Drag either floating-note corner control without waiting for a hold. A thin
  boundary follows resizing while note content keeps its previous size, then
  refits once after release.
- Tap a figure directly with one finger to open its move/resize/delete controls,
  including in inactive notes. Scrolling, pinching and stylus writing retain
  their existing gestures.
- Open the notes tray beside its toolbox button. Each minimized note has a page
  icon to restore it, with the note name in its tooltip/accessibility label.
- Change blank/lined backgrounds from the top-left **⋮** menu. This control has
  been removed from the toolbox; PDF pages retain their original backgrounds.
- Reuse indexed page geometry and bounded exact ink outlines, prepare visible
  figures on a worker, and share optional cache budgets across visible notes.
  Memory trimming retains current sharp pixels and native writing contents.

### Validation and compatibility

The final **versionCode 64** APK passed **246,324 host assertions in 60 suites**,
Debug/Release lint and builds, package/signature checks and verification against
the pinned permanent certificate. Its compiled application code matches dev.9;
the promotion changes version and release metadata only.

**This exact APK and the latest UI changes have not been physically tested on
the tablet.** The owner authorized continuing without the device and publishing
this release. Earlier optimization candidates through dev.4 passed connected
tests on **MatePad Paper HMW-W09, Android 10/API 29, firmware
HMW-W09 2.1.0.222(C00E170R1P8)**, including 58 checks on code 58. Those results
do not establish physical acceptance of the new drag/resize, figure-tap, tray
or background-menu interactions.

See the [optimization measurements](https://github.com/xing-phys/Scriflow/blob/v0.33.1/docs/optimization-0.33.1.md),
[interaction record](https://github.com/xing-phys/Scriflow/blob/v0.33.1/docs/window-figure-interactions.md),
[device record](https://github.com/xing-phys/Scriflow/blob/v0.33.1/docs/device-testing.md)
and [user guide](https://github.com/xing-phys/Scriflow/blob/v0.33.1/docs/user-guide.md).
Workload-specific cache/geometry measurements are not whole-app speed or memory
guarantees. Other devices/firmware, battery life, optical pen latency, physical
cover sensing and very long sessions remain unverified. The documented limitation
for very fast maximum-width erasing remains. No system or firmware settings
need changing.

### Install/update

Download `scriflow-0.33.1.apk` and verify its adjacent SHA-256 file. Install as an
**in-place update** without uninstalling the existing app. Keep verified editable
`.inkbook` backups outside app storage before updating. **Editing writes page
format 6, which older APKs cannot open; do not downgrade an upgraded notebook.**
This release introduces no further storage-format change.
