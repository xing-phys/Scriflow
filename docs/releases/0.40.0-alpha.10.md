# Scriflow 0.40.0-alpha.10

Browser pages keep their live state through rotation, saved copies remember
reading positions, and the toolbox stays accessible above floating chats.
Android versionCode is **110**.

- Remove the routine page/tab-count row from the toolbox. Show saving progress
  and capture warnings only when needed.
- Resize existing live pages, note surfaces and chat windows on rotation. Keep
  form input, scroll, tab sessions and captures; avoid duplicate engine activation.
- Keep the single toolbox and status above floating notes/chats after opening,
  activation and restoration. Preserve native handwriting barriers and keyboard input.
- Closing or minimizing the browser's last chat leaves the browser and notes open.
- Reopen each saved copy at its last reading position, including after app restart.
  Checkpoints are separate from archive bytes; offline scripts/network stay blocked.
- Keep the tab picker open when closing tabs, in list and thumbnail views. Update
  the count, current-tab marker and scroll without reloading an unaffected tab.

The permanently signed APK and checksum are attached. Install as an update
without uninstalling. The APK remains approximately **228 MB**. Notebook, chat
and website archive formats are unchanged; **0.33.2** remains Latest stable.

Validation covers regressions, Android debug/release lint/builds, and native
emulator checks at 4:3 portrait/landscape sizes. Native-controller note checks
use the explicit debug software surface. Physical Huawei handwriting, rotation,
Eudic and e-ink acceptance remain pending.
