# Scriflow 0.48.0-beta.4 — Compact shelf and reading controls

- Smaller, closer bookshelf shortcuts leave room for a bordered folder path.
  Open PDFs and ebooks through Files; duplicate bookshelf import buttons are gone.
- Rounded thumbnail cards contain the preview, name, actions and last-opened
  time. Older notebook entries show a dash until opened with this version.
- Dialog titles are larger and vertically centered. Page information has Export
  PDF, Reset tools and Close icons beside its title and a visible outline.
- Reading settings stay open for multiple choices. Tap outside to apply and close;
  manual and semi-auto crop open their crop editor.
- Screen sleep pauses an active cast and clears viewer frames. Unlocking and
  returning to Scriflow resumes the same session when Android and Wi-Fi keep it
  alive. Android still requires confirmation for each new capture session.

Host, Android lint/build and emulator checks cover these controls, the Files PDF
flow and cast sleep behavior. Physical MatePad, e-ink, and device-specific cast
behavior remain untested.

Known issue: A new notebook can inherit a deleted notebook's saved workspace
position when the same notebook slot is reused. This predates this release.

VersionCode **130**. Notebook pages, the version-3 library catalog, ebooks,
backups and chat formats are unchanged from 0.48.0-beta.3. Older APKs still
cannot read a library catalog written in version 3. **0.33.2 remains Latest
stable.**
