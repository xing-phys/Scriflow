# Scriflow 0.42.0-alpha.1 — Offline books

Adds **Books** for EPUB, MOBI/AZW3, DjVu, FB2/zipped FB2, CBZ, HTML and TXT.
Open books from the shelf, Files, or Android's Open with / Share menu.

- Adjust fonts, size, weight, spacing, margins, alignment, columns and scrolling;
  import TTF/OTF fonts. Fixed pages support fit and zoom.
- Use contents, full-book text search, bookmarks, highlights, text notes,
  progress restoration, Eudic lookup, focus reading and internal-link history.
- Export reading annotations as JSON or Markdown.
- **Handwrite** opens a native notebook linked to the passage. Links follow
  text after font/layout changes. Android Back returns to the book.
- **More → Write on a fixed copy of this view** opens a one-page PDF of the
  visible reading area for direct writing with the existing notebook tools.

DRM-protected books, KFX and indirect DjVu component sets are unsupported.
The fixed copy captures the current visible view at screen resolution, rather
than converting the whole book. Large bundled DjVu files use page-by-page
loading without text selection/search; scans need an existing text layer.
JSON annotation import is not implemented. Back up linked handwriting as
ordinary `.inkbook` notebooks and keep original ebooks outside private storage.
See [the reading guide](https://github.com/xing-phys/Scriflow/blob/v0.42.0-alpha.1/docs/ebook-reading.md)
for complete limits and controls.

Book rendering is offline, with pinned bundled engines and blocked book scripts
and network content. Existing PDF reading, handwriting and Files remain available.

Validation includes host regressions, 32 production-browser format/layout/security
assertions, 20 Android 10 Gecko checks covering reading, fonts, reflow/reopen,
native handwritten-note links and a nonblank imported PDF copy, Android lint/builds and
the pinned permanent release signer. Hardware-specific handwriting and e-ink
behavior still require the owner's MatePad Paper testing.

Install the attached signed APK to update the existing app. The SHA-256 file
verifies its bytes. VersionCode **114**. This is an alpha prerelease;
**0.33.2 remains Latest stable**.
