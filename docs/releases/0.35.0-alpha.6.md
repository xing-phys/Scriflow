Scriflow **0.35.0-alpha.6** (versionCode **79**) presents controls as separate floating circles.

### UI changes

- The top-left three dots open action circles below and outside the compact note bar. Circles have 6 dp gaps and wrap onto another row on narrow panes. The three dots remain available to close the actions; choosing an action or interacting with the page also closes them.
- Undo/Redo appear as separate circles outside the right status pill, with 8 dp spacing. Each still appears only when available in the existing writing context; navigation and other interactions hide them, and Zen hides both.
- The toolbox has no enclosing bar. Its individual circles have 6 dp gaps. Grip dragging, collapse/expand, orientation switching, narrow-pane scrolling, note-tray anchoring and foreground layer order remain available.
- The clock's inner View has a transparent background, removing the square white patch over its rounded Zen container.
- Persistent paper paints behind the floating groups so page content can show between circles. Native input protection remains in place. The clear Markdown/page renderer from alpha.5 is retained.

### Validation

**252,206 JVM assertions in 84 suites and six browser cases pass**, along with Android debug/release lint/build and permanent-signature checks. Existing action dispatch, popup positioning/failure handling, narrow-pane sizing, history visibility, Zen clock, note-tray and rendering regressions remain included. There is no connected tablet; physical placement, touch interaction and e-ink appearance still require confirmation.

### Install

Download `scriflow-0.35.0-alpha.6.apk` and its checksum. Install as an in-place update without uninstalling. The application ID and permanent signer are retained. Editable data, vector appearances, exports and page format 8 are unchanged. Preserve editable backups; APKs before 0.34 (including stable 0.33.2) cannot read notes edited in format 8. **0.33.2 remains Latest stable.**
