# Scriflow 0.49.0-rc.1

The APK and checksum were replaced to include the new Scriflow icon. The
replacement has Android version code 134; the original APK had version code
132. The release tag was moved, with the owner's permission, to source that
matches the replacement APK. Because the displayed version name is unchanged,
install the replacement APK manually; the in-app update checker does not offer
it as a newer version.

- Download files directly from websites and manage transfers from the browser.
  Files are saved in Downloads, where Scriflow's file manager can open them.
  Transfers use the original website response and never overwrite another file.
- Enlarge the notebook preview area on bookshelf cards.
- Name new unnamed normal and quick notes `yyMM.ddHHx`, where `x` is the
  minute divided by six, rounded down. A note created at 18:48–18:53 on
  2026-11-26 is named `2611.26188`.
- Keep old saved window positions from being applied to a new notebook that
  reuses the ID of a permanently deleted notebook.
- See the installed version and check for updates under **Settings → About**.
  Choose whether to include preview releases and whether to delete an installer
  automatically after a successful update. Downloads are checked against the
  release checksum and the installed app's signing key before Android's normal
  installation confirmation.

Downloads interrupted by an app or device stop need to be started again from the
website. Removing a download from history leaves the downloaded file in place.
Existing notebook, catalog, ebook, backup and chat formats are unchanged.

The Android 10 emulator checks cover authenticated POST downloads, duplicate
filenames, cancellation and interruption, notebook-slot reuse, the Android
installer, a live release download and checksum, signing-key rejection and
successful-update cleanup. On the
connected MatePad Paper, the RC was checked with both unnamed-note paths,
thumbnail sizing, a browser download, the Downloads folder in Files, About
settings and a live update check. These checks do not measure physical stylus
pressure or handwriting latency.
