# Scriflow 0.46.0-alpha.1 — Spreads and input responsiveness

- In PDF and note **Reading view**, choose whether double-page spreads start
  with **Pages 1–2** or a single cover followed by **2–3**. The choice is
  saved separately for each notebook and works with scrolling and page turns.
- Tapping the ebook title now goes back a page instead of leaving the book.
  Use **More → Return to bookshelf**, or press Android Back twice within two
  seconds, to avoid accidental exits during page turns.
- Casting holds the last safe picture during lasso and eraser contact and
  resumes shortly after lift. This reduces competing capture work while the
  native trail is drawn; viewers see a temporary pause during these gestures.
- Tap an individual folder in the file-manager path bar to jump directly to
  it. Common icon controls in Files, the bookshelf, browser and saved websites
  have smaller circular outlines while retaining their touch areas.

Install the attached permanently signed APK over the existing app and verify
the attached SHA-256 checksum. VersionCode **123**. Notebook, ink, PDF, backup
and saved-page formats are unchanged. The per-notebook reading preference format
advances to version 4: older APKs cannot read preferences updated by this version.

Automated host, browser and emulator tests do not establish physical MatePad
touch or e-ink behavior. In particular, the improvement to lasso/eraser latency
while casting needs a physical tablet check. **0.33.2 remains Latest stable.**
