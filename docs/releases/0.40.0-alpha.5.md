# Scriflow 0.40.0-alpha.5

The browser adds list/thumbnail views, smaller controls for the 10.3-inch 4:3
tablet, and fixes for floating dictionary windows and offline-save readiness.
This continues the browser alpha series with Android versionCode **105**.

- **List or thumbnails:** independent, remembered view switches for pinned
  websites, bookmarks and tabs. Cards retain their menu/close controls and the
  current-tab marker. Previews are monochrome 4:3 snapshots of visited pages;
  unvisited websites have a local placeholder. Library views never open websites
  or fetch favicons to generate previews. The disposable private cache is bounded
  to 160 images or 16 MB and resets when browser data is cleared.
- **Tablet layout:** smaller 20 dp symbols keep 48 dp touch targets. The floating
  panel is at most 480 dp wide, and preview layouts follow the available width in
  portrait and landscape.
- **Floating dictionaries:** keep the page session active while its Activity is
  paused but still visible behind a floating dictionary window. Deactivate when
  fully covered or when the tab is hidden, preventing the early compositor
  shutdown that cleared the page behind an Eudic lookup.
- **Offline saving:** connect capture at document start and enable it on readable
  content, including pages with unfinished network requests. Reconnect after
  cached-page restoration, allow a bounded connection grace period, and preserve
  writer ownership across cancellation. Capture, storage and size-limit failures
  have capture-specific messages instead of an indefinite rendering instruction.

The permanently signed APK and checksum are attached. Install as an in-place
update without uninstalling. The APK remains approximately **228 MB**. Notebook,
chat and offline archive formats are unchanged.

Validation includes host/browser/PDF regressions, production visibility and
capture-retry callbacks, a shipped-bridge fixture with a permanently pending
resource, cached-page restoration and cancellation, and Android debug/release
lint/builds. Native emulator checks use real 1404 × 1872 portrait and
1872 × 1404 landscape windows, create previews, switch view modes, browse GitHub,
save/reopen the reported math page and navigate offline sections. The math page
still renders all 168 formulas. A floating PROCESS_TEXT Activity leaves the
paused browser's webpage visible and intact on return. The real-cookie data
fixture verifies preview deletion and preservation of bookmark/offline data.

Physical Huawei tablet layout, Eudic's own floating window and e-ink acceptance
remain pending. The dictionary fixture verifies the Android lifecycle condition;
it is included only in debug builds. **0.33.2** remains Latest stable.

See [Browser and offline websites](https://github.com/xing-phys/Scriflow/blob/main/docs/browser.md)
for the controls and capture limits.
