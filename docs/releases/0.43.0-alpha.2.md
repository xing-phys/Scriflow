# Scriflow 0.43.0-alpha.2 — Responsive lecture casting

Improves screen casting for reports, talks and lectures after the owner
confirmed the first cast works and reported delayed lasso/region-eraser dashes.

- Capture, JPEG memory/GC and network work run in a separate Android process.
  The pen/UI process sends only small control messages and never waits for a
  frame or JPEG. Pen input and note-saving paths retain their existing behavior.
- Capture acquires the latest image at a paced slot, reuses work buffers,
  reserves more time during pen/lasso/region contact, and detaches when no
  viewer remains. Ordinary tool-popup handoffs do not restart the display.
- Higher-quality JPEGs retain native tablet pixels up to a 2048-pixel edge.
  Waiting requests replace the fixed 300 ms viewer polling delay.
- The browser swaps only decoded pictures, keeps the previous valid picture
  during a slow/corrupt replacement, and uses a white pause panel. There is no
  immediate swap to a transient all-black compositor frame; persistent black
  content is confirmed for 250 ms. Each viewer follows the newest available
  image without an accumulating playback queue.

Use the same **Settings → Screen cast** flow and password-protected local
**http://IP:port/** address. Multiple viewers, full-screen view, orientation,
private Settings/cast controls and Stop remain available. The local HTTP
connection is not encrypted; continue to use trusted Wi-Fi.
After updating and restarting the cast, reload the viewer page to load the
new delivery and image-stability code.

Capture has ceilings of eight frames/s normally and six during pen contact,
and slows further when measured encoding cost needs a larger input reserve.
Actual Huawei/Wi-Fi throughput and optical pen latency are not established by
these ceilings. GPU, memory bandwidth and Wi-Fi remain shared hardware resources.
This is for notes/lectures, rather than 30/60 fps video.

Validation includes **111** host pacing/ownership/socket checks, **28** real
Chromium viewer checks and **21** Android 10 process/capture/lifecycle checks,
including idle wake-up and controller death. Existing host/browser/AI/PDF
regressions, Android lint/builds and the permanent signing certificate pass.
Physical Huawei lasso and region-eraser response and the improved
Mac/Safari lecture experience remain owner testing checks.

Install the attached permanently signed APK over the existing app. The SHA-256
file verifies its bytes. VersionCode **118**; notebook/backup formats unchanged.
This is an alpha prerelease; **0.33.2 remains Latest stable**.
