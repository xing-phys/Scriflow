# Scriflow 0.39.0-alpha.2

- Hold notebooks in Trash, select more or **Select all**, then choose **Actions
  → Delete selected permanently**. A confirmation identifies the number of
  notebooks. Confirmed deletion cannot be undone; interrupted batches finish
  on retry or restart.
- In a main-window chat, every note can be minimized. The note-specific
  top-left bar hides until a note is restored from the toolbox notes tray. The
  bookshelf's **AI chat** button starts a new chat or opens saved chat history
  directly in the main window.
- Floating note and chat resize boundaries stay above the original window while
  growing or shrinking. Message-bar icons are vertically centered and closer
  together.
- AI responses stream into the Markdown view as text arrives, with updates
  coalesced for e-ink and handwriting. Stop or interruption retains the visible
  partial answer; a provider returning an ordinary JSON response is still
  supported. No hidden reasoning is shown.

The APK is versionCode 97 and uses the permanent release signing certificate.
Notebook and chat archive formats are unchanged from alpha.1. Earlier APKs
cannot read chat archives from newly added provider profiles or restore the new
window layout; the earlier page-format-9 limitation still applies to individually
sized Markdown.

Host regressions, offline browser and PDF checks, Android builds and lint, and
release signing verification passed. No tablet or live provider account was
available. Please verify chat-only mode, restoring notes, resized boundaries,
the message bar, streaming and handwriting on the target device.
