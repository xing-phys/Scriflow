Scriflow **0.37.0-alpha.1** (versionCode **89**) adds multiple floating AI chats with the same window controls as floating notes.

## Multiple chats and familiar controls

- Tap the toolbox AI icon to open a chat. Once windows exist, it toggles a tray with **+** for a new floating chat and bubble icons for minimized chats. The header's **+** also opens a separate chat using that window's model.
- **Bottom-left:** tap for options; drag to move. **Bottom-right:** tap to minimize; drag to resize. Notes and chats share the actual control/gesture code, geometry and thin four-edge resize outline. The top-left corner stays anchored; the right and bottom edges follow the gesture within the workspace, with content refitting on release. The separate clipped frame is retained.
- The same menus offer **Position**, **Minimize**, **Close chat**, and size presets. Choose **Left, Right, Top, Bottom, or Floating window**. A chat dock reserves the remaining area for notes; minimizing or closing it returns that space.
- Each window keeps its own session, draft, model and request. Minimizing preserves an already-started reply and releases its Markdown renderer until restoration. Closing keeps history and stops only that window's request. Other chats remain open and continue independently.
- Windows, placements and minimized states restore after rotation, Settings, backgrounding and app reopen. Existing windows keep their original model when the default changes. Interrupted questions wait for an explicit Retry.
- History opens another window, or restores/raises the existing owner if that session is already open. Deleting a session displayed in another window closes that window. Notebook selections append to the last active chat, restoring it if minimized, without sending automatically.
