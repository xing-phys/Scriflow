Scriflow 0.33.2 adds in-note figure editing and compact note controls. It includes
all changes through 0.33.2-dev.6 while retaining the existing application ID and
permanent signing identity for in-place updates.

### Changes

- Use the compact top-left bar for notebook navigation: tap the name for the
  bookshelf, the page counter for page management, or the percentage for zoom.
  Previous/next arrows flank the counter. Tap **⋮** to replace it with function
  icons within the same bar, which stretches to fit.
- Undo/Redo appear individually beside the top-right status only when available
  after writing. Navigation and other interactions hide them until writing
  resumes. These controls no longer occupy the toolbox.
- Toggle **Zen mode** from the toolbox to hide the left bar and history and keep
  only a tiny right-side clock with seconds. Tap again to restore. Note layout,
  zoom and tools retain their state.
- **Insert figure** opens the system file picker directly and returns to the
  note after insertion or cancellation. Tap a figure to edit it within the
  existing view, without a separate editor or Apply/Cancel footer.
- Drag figures to move, resize or rotate to any angle. Nearby icons offer Copy,
  Cut, Delete and Paste; tap outside to finish. Drag across pages with edge
  scrolling and linked undo/redo. Rotation preserves original PNG pixels and
  is retained in thumbnails, PDF export and editable backups.
- Lasso selection actions use compact icons for Copy, Duplicate, Move to page,
  Cut, Delete and Export. Tap outside to finish; there is no Done button or text
  header. Icons wrap in narrow panes and retain tooltips/accessibility labels.

### Storage compatibility

**Back up before updating. This is the first public release that writes page
format 7. Older APKs, including 0.33.1, cannot open pages edited by this release
or newly created editable backups. Do not downgrade an upgraded notebook.**

Existing page versions 1–6 and old `.inkbook` backups remain readable. Opening a
page does not rewrite it; its first successful edit publishes format 7 and
retains the predecessor snapshot. New editable backups contain format-7 page
snapshots even for unedited notes. Format 7 was introduced in compatible local
0.33.2-dev.5 builds; it stores a figure's rotation without resampling the PNG.
Keep independent, verified editable backups outside app storage before updating.

### Validation and limits

The final **versionCode 71** APK passes **248,470 host assertions in 68 suites**,
debug/release lint and builds, package/signature checks and verification against
the pinned permanent certificate. Its DEX code is identical to dev.6; promotion
changes version and documentation metadata only. Host coverage includes migration,
rotated geometry/export, linked history and interrupted-save recovery, contextual
icons, native pause/repair/resume ordering and narrow-pane action reflow.

**This exact APK and the recent UI/figure interactions have not been physically
tested on the tablet.** The owner explicitly authorized publication while
continuing without the device. Earlier connected results and the accepted
M-Pencil body shortcut do not replace acceptance of the new bars, Zen mode,
figure picker/rotation/cross-page gestures or icon strips.

Development targets **MatePad Paper HMW-W09, Android 10/API 29, firmware
HMW-W09 2.1.0.222(C00E170R1P8)**. Other hardware/firmware, battery life, optical
pen latency, physical cover sensing and very long sessions remain unverified.
The documented limitation for very fast maximum-width erasing remains. No
system or firmware settings need changing.

### Install/update

Download `scriflow-0.33.2.apk` and verify its adjacent SHA-256 file. Install as an
**in-place update**, without uninstalling the existing app. Uninstalling or
clearing app storage deletes private notes. The application ID remains
`org.eink.inkprobe` and the signing key is unchanged.
