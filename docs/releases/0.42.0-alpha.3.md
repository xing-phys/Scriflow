# Scriflow 0.42.0-alpha.3 — Unified homepage and floating reader controls

Ebooks now appear directly alongside PDFs and notes on Scriflow's homepage.
Existing imports appear automatically; no reimport is needed.

- Use the existing list or thumbnail layout for ebooks, PDFs and notebooks.
  Rename ebooks, move them into ordinary folders, select them alongside notes,
  and use the shared Trash. Removing a folder keeps its items on the homepage.
- Read with the same native floating top-left and top-right bars as notebooks,
  plus a movable icon toolbox. The page fills the screen; the old full-width
  header/footer button rows are removed.
- Tap the toolbox grip to expand/collapse it, or drag it to move it. Its icons
  provide text/layout settings, contents, search, bookmarks, notes, handwriting
  and focus mode. Text selection reveals its contextual action icons.
- The top-left bar provides the title, page arrows, progress and more menu.
  The top-right bar shows device status and available link-history actions.
- Homepage import and action shortcuts use icons with accessible names.

Existing original books, reading progress, annotations and handwritten-note links
are preserved. Custom homepage names survive reopening and publisher metadata
updates. Permanent ebook deletion requires Trash and confirmation; original
tablet files and linked handwritten notebooks are retained.

Validation: full host regressions, 35 ebook storage assertions, 20 shelf-selection
assertions, 33 browser format/layout/security assertions, 21 Android Gecko reader
checks, actual floating-toolbox/font-menu interaction, homepage rename/folder/
selection/Trash checks, list and thumbnail rendering, Android debug/release lint
and builds, and the pinned permanent release signer.

Install the attached signed APK to update. The SHA-256 file verifies its bytes.
VersionCode **116**. This alpha awaits physical Huawei pen, e-ink and owner UI
acceptance. **0.33.2 remains Latest stable**.

for controls and format limits.
