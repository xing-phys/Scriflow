Scriflow **0.36.0-alpha.1** (versionCode **83**) makes the implemented **AI chat** feature available for early tablet testing.

### Use

1. Open **Settings → AI chat** from the time/battery/Wi-Fi pill.
2. Choose OpenAI, Anthropic, Google Gemini, DeepSeek, or a custom OpenAI-compatible HTTPS endpoint. Enter your API key, check the model and API base URL, and tap **Save AI settings**.
3. Tap the toolbox's **chat-bubble sparkle**. Drag the floating chat's title to move it or its lower-right handle to resize it.

Replies render Markdown, equations, tables, code, Mermaid diagrams and multilingual text using the existing local renderer. Follow-up questions include the conversation's earlier turns. **Stop**, **Retry**, **Copy reply**, **New chat (+)** and **Close (×)** are available. Closing preserves the transcript and unsent draft. Each provider/endpoint/model has its own current conversation.

### Privacy

Sending or retrying shares the chat's text history directly with your configured provider; its data policies and API usage charges apply. Notebook pages, handwriting, figures and PDFs are not attached automatically. API keys are encrypted using Android Keystore. Chat history and drafts are unencrypted app-private files, outside notebook backups. The Markdown WebView blocks external requests and has no credential access. API requests require HTTPS and do not follow redirects.

### Validation and testing

This alpha promotes **0.36.0-dev.1 with version and documentation changes only**. All DEX files are byte-identical to the verified dev.1 build. The feature passed **272,567 JVM assertions in 91 suites and eleven browser cases**, plus Android debug/release lint and builds. The alpha passes Android packaging/lint, permanent-signature verification and comparison of published assets with local bytes.

**Tablet and live-provider testing follow this release.** Please test provider configuration, sending/follow-ups, Markdown/math display, keyboard layout, window movement/resizing, and writing beside the chat on the MatePad. These physical interactions and live account requests have not yet been accepted. Host checks do not establish e-ink appearance, stylus latency or long-chat resource use.

### Install

Download **`scriflow-0.36.0-alpha.1.apk`** and its SHA-256 file from the assets below. Install as an in-place update **without uninstalling**. VersionCode 83 supports updating both alpha.8 and AI dev.1. The application ID and permanent signing identity are retained.

Page/backup format **8** is unchanged. Keep editable backups before updating; APKs before 0.34, including stable 0.33.2, cannot read notes edited in format 8. **0.33.2 remains Latest stable.**

Compatibility remains Huawei MatePad Paper HMW-W09, Android 10/API 29, firmware `HMW-W09 2.1.0.222(C00E170R1P8)`; other devices/firmware are unverified.
