# Scriflow 0.47.0-alpha.1 — Screenful reading taps

- In continuous PDF and note views, tapping advances through the visible
  screen instead of immediately jumping to the next page. The upper-left tap
  moves backward; page arrows still jump directly between pages or spreads.
- In **Reading view → Tap overlap**, choose how much of the prior screen stays
  visible. The range is **0–80%**, with a **10%** default, saved independently
  for each notebook. Horizontal continuous reading moves down through a tall
  page first and then across the strip.
- Page turns mode, selection, links, figures and stylus input retain their
  established behavior. The same setting applies to floating and split notes.

Install the attached permanently signed APK over the existing app and verify
the attached SHA-256 checksum. VersionCode **125**. Notebook, ink, PDF, ebook,
backup and saved-page formats are unchanged. Reading preferences advance to
version 5; older APKs cannot read preference files updated by this version.

Emulator and host checks do not establish physical MatePad behavior. The EPUB
return-to-bookshelf report remains unconfirmed without a tablet crash log;
see alpha.2 for the reproduced chapter-transition error that was fixed.
**0.33.2 remains Latest stable.**
